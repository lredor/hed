## 0.1.0

First release of Home Electrical Designer, a Sirius Web modeler for documenting a home's electrical installation.

- Describe the dwelling, storeys, rooms and terminal equipment, with a reusable device-type catalog.
- Model distribution boards, DIN rails, protection devices, circuits, optional branches and control functions.
- Create, edit, reorder and move elements in Model Explorer, with catalog drag and drop, navigation and optional completeness highlights.
- Browse equipment, circuits, distribution boards and catalog types in tables.
- Arrange modular devices in a physical distribution-board diagram and place equipment on storey floor plans with background images.
- Explore connections in the **experimental Circuit Diagram**. This representation will evolve; existing circuit diagrams may need to be recreated in later releases.
- Use the English or French interface, localized sample projects and bundled user guides.
- Install the ready-to-run Linux amd64 Docker image without compiling sources or supplying a GitHub token.

HED documents a design; it does not certify compliance with electrical regulations.
